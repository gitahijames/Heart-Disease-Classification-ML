# Heart Disease Classification Using Machine Learning

## Project Overview

This project applies machine learning techniques to classify whether a patient is likely to have heart disease based on clinical and demographic features.

The project compares two supervised machine learning algorithms:

- Decision Tree
- Random Forest

## Objectives

- Explore and preprocess the heart disease dataset.
- Handle missing values and duplicate records.
- Identify numerical and categorical features.
- Encode categorical variables using one-hot encoding.
- Split the data into training and testing sets.
- Train a Decision Tree classification model.
- Train a Random Forest classification model.
- Tune model hyperparameters.
- Evaluate and compare model performance.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Techniques

### Decision Tree
A Decision Tree model is used to classify patients into heart disease outcome categories based on the available features.

### Random Forest
A Random Forest model combines multiple decision trees to improve classification performance and robustness.

## Model Evaluation

The models are evaluated using classification performance metrics such as:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Project Files

- `heart disease.ipynb` — Complete Jupyter Notebook containing data preprocessing, exploratory analysis, model training, hyperparameter tuning, and evaluation.
